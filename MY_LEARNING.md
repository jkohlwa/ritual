# Quick Notes from the Workshop

Flow I remember:
1. Create market + set resolve block
2. People bet
3. Scheduler calls the contract
4. Fetch price with HTTP precompile
5. jq pulls the number
6. Decide YES / NO / Invalid
7. Winners claim

Cool parts:
- Three retries
- Different executor each try
- Never forces a wrong result

Still curious how expensive the HTTP calls will be on mainnet, but overall really clear workshop.
